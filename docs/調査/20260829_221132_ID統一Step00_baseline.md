このreceiptは次を証明する。

1. 現行productionは`job_id == trace_id`であり、正本が禁止するidentity兼用が実在する。

3. target requestはHTTP 400で失敗し、Actor responseは得られなかった。
4. 同じrequestの自動再実行は行っていない。

Gateway journalではrouting用requestはcompleted、Actor応答用requestはfailedである。詳細な400 response bodyは現行journalに記録されておらず、原因はこのbaseline時点では未確定である。
