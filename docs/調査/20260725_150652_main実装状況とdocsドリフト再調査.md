## 履歴で判定した新旧

- PORTALの`IdleChat`正規名はRenCrow_PORTAL commit `18ac2ef`で2026-07-25に導入され、
  COREに残っていた2026-07-15から17の`view`正規名記述より新しい。
- Memory共有scopeは機能仕様の「同じ認証済み利用者と許可scope」が、character仕様の
  無条件に読める記述より具体的で安全側の契約である。
- Backup順序の文書は同じcommit内で食い違っていたため、新旧ではなく実スクリプトを証拠にした。
- 非同期UserMemory仕様と実装状況は同じcommitで追加されており、契約自体は維持しつつ、
  各文書で「採用済み・未実装」を明示した。

## 是正実装後の確認

調査後の是正で、UserMemory非同期昇格は永続queue、有限再試行、candidate保存、
失敗観測APIを持つ`MemoryPromotionWorker`としてproduction wiringへ接続した。
Role profile観測はLLM Gatewayのconfig、binding、request解決、status、errorへ接続し、
agent、role、alias、revision、target、provider、modelを同じ実行結果から返す。
Advisorの日次score snapshotと採用記録、Revenue／Workstream／Advisor routeの
feature ownership移管、CMDのIdleChat操作も実装・test済みである。

Economic traceのDeliveryモデル、ASSISTANTの認証・device pairing・wire schema、
旧CORE Viewerの削除時期は製品判断を伴うため未確定として残す。
