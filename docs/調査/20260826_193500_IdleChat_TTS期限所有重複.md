# IdleChat TTS期限所有重複

## Failure

IdleChatの通常発話とsummaryについて、合成の`Ready`と`Done`、Viewer再生ACK、timeoutを同じ完了概念として扱い、さらにorchestratorとqueue／prefetch workerの双方で固定timeoutを開始していた。

## Problem

- 次ターンが全chunk合成または再生ACKに引きずられた。
- timeout後も下流合成が続き、遅延chunkが後続sessionへ到着し得た。
- summaryのような複数chunk発話では、workerの時計がqueue／prefetch作成時から進むため、session drainの期限内でも末尾chunkが先にcancelされた。
- request側の長さとGateway／backend遅延を区別するreceiptがなく、長文入力か下流変動かを判定できなかった。

## Cause

「合成開始可能」「先頭音声利用可能」「全chunk合成完了」「Viewer再生完了」「会話session完了」を一つのTTS完了へ畳み込み、deadlineの所有者を一意にしていなかった。2026-08-26のcanonical E2Eではsummaryを10 request（各10〜45 speech rune）へ分割できていた一方、prefetch作成から120秒のworker deadlineが10本目を`context deadline exceeded`で中断した。session drain開始からはまだ120秒未満だった。

## Lesson

TTS遅延は単一の秒数では管理しない。発話identityごとに、先頭chunk、各Gateway request、全発話、再生ACK、session drainを別の状態とreceiptとして扱う。長文対策は共通chunkerで決定し、timeout延長で隠さない。

## Invariant

- 進行待ちは最初の音声chunkまたはterminalを表す`Ready`だけを消費する。
- session終了時だけ全chunk terminalを表す`Done`をdrainする。
- Viewer再生ACKは観測とcache解放だけを所有し、合成開始や`Ready`／`Done`を確定しない。
- `Ready`待ちとsession drainを持つorchestratorだけがdeadlineを所有する。queue投入時またはprefetch作成時に競合する固定deadlineを開始しない。
- timeout／stop／resetは同じ発話のcontextをGatewayまでcancelし、以後のrequestを開始しない。
- topic、通常発話、summary、prefetchは同じ目標34 rune・本文最大42 runeのchunkerを使い、句点とemotion prefix込みのGateway payloadを44 rune以内にする。
- summaryは3観点を維持したまま読み上げ全体を7 chunk以内にし、超過時の短縮生成は1回に限定する。

## Enforcement

- `TTSLifecycle{Ready, Done}`をCOREのIdleChat境界で使用する。
- active synthesis contextをsession／message identityで登録し、timeout reporterからcancelする。
- TTS bridgeで`session`、`chunk`、`plan_index/count`、`speech_runes`、`elapsed_ms`、失敗理由を記録する。
- worker contextは`context.WithCancel`とし、独自deadlineを持たない。

## Tests

- 最初のchunkで`Ready`となり、後続chunk合成中でも次ターンへ進めること。
- `Done`が全chunk terminalまで閉じないこと。
- playback ACKなしでも合成が進み、ACKがpending stateだけを解放すること。
- timeoutがactive synthesis contextをcancelし、遅延callbackが状態を復活させないこと。
- queue／prefetch contextに独自deadlineがないこと。
- 通常発話とsummaryの全Gateway payloadが44 rune以内で、summary読み上げが7 chunk以内であること。
- canonical E2Eで12発話、3観点summary、全TTS request、session drainがtimeoutなしで完了すること。
