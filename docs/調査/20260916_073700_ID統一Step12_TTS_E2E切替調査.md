- Lesson: TTS E2E は「Irodori ready」だけでは足りない。CORE Action lineage と Gateway echo 契約の両方が必要。

- Enforcement: CORE `postSynthesisWithRetry` の identity mismatch。次は Gateway 側 echo 契約の TDD。
